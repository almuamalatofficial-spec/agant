# Aqdlar bo'yicha nazorat ro'yxatlari

Har bir fayl — bitta shartnoma turi: ta'rif, ruknlar, majburiy shartlar, to'g'ri ketma-ketlik, tipik xatolar
(ayniqsa an'anaviy hujjatdan ko'chirilganda), Grep uchun xavf so'zlari.

Foydalanish: shariat-moslashtiruvchi, shariat-auditor, aaoifi-nazoratchi, mohiyat-tekshiruvchi, fatvo-xotirasi
va hisob-tekshiruvchi hujjatda uchragan aqd turlari bo'yicha tegishli faylni yuklaydi.

Eslatma: AAOIFI standart raqamlari ko'rsatilgan, band raqamlari — `bilim/00-umumiy/aaoifi/` dagi matn bilan
tasdiqlanadi. "IMK bilan aniqlansin" — fiqhiy ixtilof yoki bankning o'z fatvosiga bog'liq masala.
Ro'yxatlarni Al Muamalat va IMK tajribasi bilan to'ldiring (yangi tipik xato topilsa — shu yerga qo'shing).
